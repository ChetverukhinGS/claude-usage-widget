# Claude usage widget

Небольшое приложение для Windows: окошко поверх остальных окон с лимитами Claude — текущая сессия и неделя, со шкалой и временем до сброса. Цифры те же, что на странице claude.ai «Настройки → Использование», и учитывают всё: чат, Claude Code, приложение.

```
Сессия  ━━━━━━━──────────  29%  сброс через 3ч 50м
Неделя  ━━━━━━━━━────────  51%  сброс через 4д 11ч
обновлено только что
```

## Как это работает

Внутри приложения — встроенный Edge (WebView2). Вы один раз входите в claude.ai в окне приложения, как в браузере; пароль приложение не видит и не хранит, вход запоминается в его собственном профиле `%LOCALAPPDATA%\ClaudeUsageWidget\WebView2`. Каждые 30 секунд приложение делает тот же запрос, что и страница «Использование» (`/api/organizations/<id>/usage`), и показывает результат.

- Цвет шкалы — как на странице «Использование»: синий `#257DE0`, при предупреждении жёлтый `#FBB315`, при критическом уровне красный `#DC3C3D` (по полю `severity` из ответа сервера; если его нет — от 80% и от 95%).
- Окошко держится поверх всех окон и панели задач. Меню «Пуск» Windows всё равно открывается поверх него — это системный слой, обычным программам туда хода нет.
- По умолчанию окошко видно, пока открыто приложение Claude для рабочего стола.

Меню по правому клику: «Обновить сейчас», «Открыть «Использование» на claude.ai», «Показывать, даже когда Claude закрыт», «Войти в другой аккаунт», «Закрыть виджет». Окошко можно перетащить мышкой, позиция запоминается.

## Требования

- Windows 10 или 11 с WebView2 Runtime (в Windows 11 есть по умолчанию).
- .NET Framework 4.6.2+ (есть в Windows 10/11) — компилятор `csc.exe` из него используется для сборки.

## Сборка

1. Скачайте NuGet-пакет [Microsoft.Web.WebView2](https://www.nuget.org/packages/Microsoft.Web.WebView2) (кнопка «Download package»). Это zip-архив с расширением `.nupkg`.
2. Положите в папку `lib` рядом с `build.ps1` два файла из архива:
   - `lib\net462\Microsoft.Web.WebView2.Core.dll`
   - `runtimes\win-x64\native\WebView2Loader.dll`
3. Выполните в PowerShell:

   ```
   powershell -ExecutionPolicy Bypass -File .\build.ps1
   ```

Готовое приложение — `bin\ClaudeUsageWidget.exe` (вместе с двумя DLL рядом). При первом запуске откроется окно входа в claude.ai.

Для автозапуска положите ярлык на `bin\ClaudeUsageWidget.exe` в папку `shell:startup` (Win+R → `shell:startup`).

## Файлы

- `app/ClaudeUsageWidget.cs` — исходный код приложения (C#, WPF, WebView2).
- `build.ps1` — сборка.
- `lib/`, `bin/` — библиотеки WebView2 и результат сборки, в репозиторий не входят.
- Настройки (позиция, «показывать всегда») — `%LOCALAPPDATA%\ClaudeUsageWidget\settings.json`.
