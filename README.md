# Claude usage widget

Небольшой виджет для Windows: окошко поверх остальных окон, которое показывает, сколько израсходовано из лимитов Claude — 5‑часового и недельного, с цветной шкалой и временем до сброса. Окошко видно только пока открыто приложение Claude для рабочего стола.

```
5 ч     ██████░░░░  46%  сброс через 2ч 14м
Неделя  ████░░░░░░  37%  сброс через 4д 19ч
обновлено 1 мин назад
```

## Требования

- Windows 10 или 11, Windows PowerShell 5.1 (есть в системе).
- Источник данных: файл `%USERPROFILE%\.claude\usage-limits.json` (формат ниже). Сам виджет лимиты не запрашивает, он только показывает этот файл. Без файла пишет «Нет данных».

## Запуск

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте в любую папку.
2. Дважды щёлкните `start-widget.vbs`.

Окошко можно перетащить мышкой, позиция запоминается. Правый клик → «Закрыть виджет». Одновременно работает только одна копия.

Для автозапуска положите ярлык на `start-widget.vbs` в папку `shell:startup` (Win+R → `shell:startup`).

## Формат данных

`%USERPROFILE%\.claude\usage-limits.json`:

```json
{
  "limits": [
    { "kind": "five_hour", "percentUsed": 46, "resetsAt": "2026-11-06T01:10:00.000Z" },
    { "kind": "seven_day", "percentUsed": 37, "resetsAt": "2026-11-10T20:00:00.000Z" }
  ],
  "seenAt": 1793914351227
}
```

- `kind`: `five_hour` или `seven_day`.
- `percentUsed`: от 0 до 100.
- `resetsAt`: время сброса в формате ISO 8601.
- `seenAt`: когда получены цифры, в миллисекундах Unix.

Виджет перечитывает файл каждые 5 секунд. Цвет шкалы: зелёный до 70%, жёлтый до 90%, красный выше.

## Файлы

- `usage-widget.ps1` — сам виджет (WPF).
- `start-widget.vbs` — запуск без окна консоли.
- Позиция окна хранится в `%USERPROFILE%\.claude\usage-widget-pos.json`.
